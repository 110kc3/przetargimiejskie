nieruchomości stanowiącej własność Gminy Sztum.

   przeprowadzono pierwszy przetarg ustny nieograniczony na sprzedaż nieruchomości
   stanowiącej własność Gminy Sztum.
2. Przedmiotem przetargu była działka nr 544/9 położona w obr. 2 miasta Sztum o pow.
   0,0316 ha.
3. Liczba osób dopuszczonych do przetargu: 0
   Liczba osób niedopuszczonych do przetargu: 0
4. Cena wywoławcza: 48 300 zł + VAT 23%
   Najwyższa cena osiągnięta w przetargu: -
   Przetarg zakończył się wynikiem negatywnym.
